IMAGE_MAP_EDITOR · 기능 설명
이미지를 업로드하고 핫스팟을 배치해 이벤트 페이지를 구성하는 에디터.
비디자이너·비개발자가 5분 내 발행하는 UX 목표.
_01상단 바›
IMAGE_MAP_EDITOR_01
상단 바
조회저장고정 상단 바
  • 이벤트명 읽기 전용 (변경은 기본 설정 화면에서)
  • 임시저장: 클릭 시 현재 시각 "마지막 저장: HH:MM" 표시 (첫 진입 시 숨김)
  • 배포대기 등록: 완료 시 안내 팝업 표시. QA 플레이스먼트 이동 링크 포함
  • 자동 저장 없음 — 수동 클릭 시에만 저장
  • 미저장 이탈 시 컨펌 팝업 (→ 09)
_02이미지 업로드 패널›
IMAGE_MAP_EDITOR_02
이미지 업로드 패널
수정세그먼트 버튼 + 업로드 슬롯
  • 게임 방향 타입 선택 필수: 세로 / 가로 / 자유 비율
  • 방향 타입 변경 시 에디터 캔버스 디바이스 모양 전환 (세로형 ↔ 가로형)
  • 슬롯 클릭 → 파일 선택 다이얼로그 열림, 선택 이미지 슬롯에 미리보기 표시
  • 세로: 세로형 필수 + PC 선택 / 가로: 가로형 필수 + PC 선택
  • 자유: 세로·가로 중 1장 이상 필수 + PC 선택. 미등록 방향 → 레터박스
  • 포맷: JPG, PNG, WebP / 모바일 최대 10MB / PC 최대 20MB
  • 업로드 완료 즉시 자동 검사 → 07번 팝업 안내
핵심 정책버튼·아이콘 등 시각 요소는 모두 업로드 이미지에 포함. 에디터는 투명 클릭 영역(핫스팟)만 정의.
_03에디터 캔버스›
IMAGE_MAP_EDITOR_03
에디터 캔버스
수정인터랙티브 캔버스
  • 이미지 위 드래그 → 사각형 핫스팟 생성
  • 클릭 선택 → 8방향 리사이즈 핸들, 드래그로 이동/크기 조절
  • 핫스팟 최대 20개
  • 색상 10종 자동 순환 부여
  • 단축키: Delete(삭제) · Ctrl+Z(취소) · Ctrl+Y(다시 실행)
⚠ 배포 렌더링핫스팟은 배포 페이지에서 투명. 에디터의 색상 박스는 제작 편의용.
_04디바이스·줌·세이프에리어›
IMAGE_MAP_EDITOR_04
디바이스·줌·세이프에리어 컨트롤
조회세그먼트 버튼 + 토글
  • 디바이스 토글: 375 / 390 / 768 / PC(1280px+) — 캔버스 폰 크기 실제 변환
  • 줌: 50%~200% (25% 단위) — 캔버스 스케일 CSS transform 적용
  • 세이프에리어 오버레이: 기본 ON, PC 선택 시 자동 OFF
  • iOS Dynamic Island 기준 고정 비율 근사값 (상 8% / 하 6% / 좌우 2%)
_05핫스팟 목록 패널›
IMAGE_MAP_EDITOR_05
핫스팟 목록 패널
조회스크롤 목록 + 추가 버튼
  • 색상 인디케이터 + 이름 + 링크 타입 레이블 표시
  • 항목 클릭 → 캔버스 핫스팟 선택 + 속성 패널 연동
  • 캔버스 핫스팟 클릭/드래그 시 목록 및 속성 패널 동기화
  • 최대 20개 — 도달 시 추가 버튼 비활성화
  • "+ 새 링크 영역 추가" → 기본 위치에 핫스팟 추가
  • 마우스로 캔버스 내 디바이스에 영역 드래그 → 신규 핫스팟 생성
_06핫스팟 속성 패널›
IMAGE_MAP_EDITOR_06
핫스팟 속성 패널
수정입력 폼 + 조건부 필드
  • 이름: 선택된 핫스팟 이름. 수정 시 목록에도 실시간 반영
  • X / Y / 너비 / 높이: % 단위. 변경 시 디바이스 내 핫스팟 위치·크기 즉시 반영
  • 링크 타입: 딥링크 / 웹 링크 / 없음(비활성) / 다국어 분기
  • 테스트 QR 생성 클릭 → 해당 영역 하단에 인라인으로 QR 표시
딥링크 정책유효성 검증·동작 보장은 게임팀 책임. 발행 전 테스트 QR로 실기기 확인 필수.
팝업 / 모달
_07이미지 업로드 검사 팝업›
IMAGE_MAP_EDITOR_07
이미지 업로드 검사 팝업
조회팝업
  • 업로드 완료 즉시 자동 실행
  • 차단(얼럿): 포맷 오류, 용량 초과 → 업로드 차단
  • 경고(컨펌): 해상도 미달 → 확인 후 업로드 또는 취소
_08유효성 체크 팝업 – 차단›
IMAGE_MAP_EDITOR_08
유효성 체크 – 차단 얼럿
조회팝업
  • 임시저장·배포대기 등록 클릭 시 실행
  • 차단 케이스: 이미지 미업로드, URL 형식 오류
  • 해소 전 저장·등록 불가
_09유효성 체크 팝업 – 경고›
IMAGE_MAP_EDITOR_09
유효성 체크 – 경고 컨펌
조회팝업
  • 차단 없고 경고 있을 때만 표시
  • 복수 경고 → 하나의 팝업에 목록 통합
  • 경고 케이스: 링크 미설정, 터치 영역 미달, 세이프에리어 침범
  • [확인] → 저장/등록 진행 / [취소] → 에디터 유지
_10실기기 테스트 QR›
IMAGE_MAP_EDITOR_10
실기기 테스트 QR
조회인라인 QR 패널
  • 속성 패널(06) > 테스트 QR 생성 클릭 시 해당 영역 하단에 인라인 표시
  • 딥링크 동작 확인 전용 (인게임)
  • 테스트 모드 플래그 → 집계 제외
  • QR 유효 시간: 30분 (카운트다운 표시)
  • 만료 시 재생성 버튼으로 갱신

스크래치 카드 표시
조회Canvas
이벤트 페이지 진입 시 스크래치 카드(복권)를 표시한다.
  • 카드 앞면에는 UI 설정(UI-01)에서 업로드한 커버 이미지가 표시된다.
  • 커버 이미지 미설정 시 기본 이미지(이벤트 빌더 기본 이미지) 사용.
  • 카드 크기: 좌우 여백을 제외한 전체 너비 기준으로 비율 유지.
F-08 스크래치 인터랙션 ›
F-08
스크래치 인터랙션
동작Canvas
유저가 카드 위를 드래그(PC: 마우스, 모바일: 터치)하면 캔버스 영역이 지워지며 아래 결과 이미지가 드러난다.
  • 긁힌 비율이 임계값(기본 60%) 이상이 되면 스크래치 완료 자동 처리.
  • 완료 시 남은 커버 영역을 애니메이션으로 전부 지우고 보상 팝업(F-05)을 표시.
  • PC 마우스 드래그 / 모바일 터치 드래그 모두 지원.
F-05 보상 획득 팝업 ›
F-05
보상 획득 팝업
조회팝업
스크래치 완료(F-08) 시 결과를 알리는 팝업을 표시한다.
  • 팝업에는 보상 이미지, 보상명, 수량이 표시된다.
  • 꽝(미당첨)인 경우 별도 안내 이미지 표시.
  • [확인] 버튼 클릭 시 팝업 닫힘.
  • 꽝 연출이 설정된 경우(UI-05), 팝업 배경에 안내 이미지 적용.
F-03 참여 대기 안내 (딤 오버레이) ›
F-03
참여 대기 안내 (딤 오버레이)
조회
참여 불가 상태일 때 스크래치 카드 위에 딤(dim) 오버레이를 표시하여 대기 상태를 안내한다.
  • 딤 위에 대기 메시지(F-06)와 카운트다운(F-04)이 표시된다.
  • 딤 상태에서는 스크래치 불가 (캔버스 터치/마우스 이벤트 차단).
F-06 참여 대기 메시지 ›
F-06
참여 대기 메시지
조회
딤 오버레이(F-03) 위에 유저에게 표시되는 대기 안내 문구.
  • UI 설정(UI-02)에서 입력한 텍스트를 그대로 사용한다.
  • 미설정 시 기본 문구 표시.
F-04 참여 가능 카운트다운 ›
F-04
참여 가능 카운트다운
조회
딤 오버레이(F-03) 내부에 다음 참여 가능 시각까지 남은 시간을 카운트다운으로 표시한다.
  • 형식: HH:MM:SS
  • 카운트다운이 0이 되면 딤이 자동 해제되고 스크래치 가능 상태로 전환.
  • UI 설정(UI-03)에서 카운트다운 노출 여부를 ON/OFF 할 수 있다.
F-09 당첨 확률 표시 영역 ›
F-09
당첨 확률 표시 영역
조회
스크래치 카드 하단에 보상 등급별 아이템명과 당첨 확률을 목록으로 표시하는 영역.
  • UI 설정(UI-04)에서 확률 노출을 OFF하면 이 영역 전체가 숨겨진다.
F-10 당첨 확률 안내 아이콘 (ⓘ) ›
F-10
당첨 확률 안내 아이콘 (ⓘ)
조회
확률 표시 영역 옆에 위치하는 ⓘ 아이콘.
  • 탭하면 당첨 확률 고지 안내(툴팁/시트)가 표시된다.
  • UI 설정(UI-04)에서 확률 노출을 OFF하면 이 아이콘도 함께 숨겨진다.

UI-01 커버 이미지 (단일) ›
UI-01
커버 이미지 (단일)
수정이미지 업로드
스크래치 카드 앞면에 표시될 커버 이미지를 업로드하는 설정 항목.
  • 단일 이미지 업로드(PNG/JPG/GIF 등).
  • 권장 해상도 및 파일 크기 제한 안내 포함.
  • 업로드된 이미지는 스크래치 카드 커버 레이어에 적용된다(F-02 연동).
  • 미업로드 시 기본 커버 이미지(회색 그라데이션)가 자동 적용.
  • 이미지 권장 규격은 디자이너 확정 후 별도 안내.
UI-02 대기 메시지 입력 ›
UI-02
대기 메시지 입력
수정텍스트 입력
참여 대기 딤(F-03) 위에 표시될 안내 문구를 어드민이 직접 입력하는 필드.
  • 텍스트 입력 필드 (최대 글자 수 제한 있음, 초과 시 입력 불가 또는 경고 표시).
  • 줄바꿈 지원 여부는 별도 확인 필요.
  • 미입력 시 서비스 기본 문구 사용 (예: "내일 다시 도전하세요!").
  • 입력한 텍스트는 F-06(참여 대기 메시지)에 실시간 반영.
UI-03 대기 카운트다운 노출 여부 ›
UI-03
대기 카운트다운 노출 여부
수정토글
딤 오버레이(F-03) 위에 카운트다운(F-04)을 표시할지 여부를 설정하는 토글.
  • ON: 다음 참여 가능 시각까지 남은 시간을 HH:MM:SS 형식으로 표시.
  • OFF: 카운트다운 숨김. 대기 메시지(UI-02)만 표시.
  • 기본값: ON.
UI-04 당첨 확률 노출 여부 ›
UI-04
당첨 확률 노출 여부
수정토글
유저 화면(웹뷰)에서 당첨 확률 목록(F-09) 및 ⓘ 아이콘(F-10)을 표시할지 여부를 설정하는 토글.
  • 노출: 카드 하단에 보상 등급별 확률표와 ⓘ 아이콘 표시.
  • 미노출: 확률표와 ⓘ 아이콘 모두 숨김.
  • 기본값: 미노출.
⚠ 주의 확률형 아이템 법적 공시 의무 이벤트의 경우 OFF 처리 시 법무 검토 필요.

UI-05
꽝 연출 이미지 설정
수정토글 + 이미지
최상위 등급 보상(꽝)에 연출 이미지를 설정하는 항목.
  • 미션&리워드 설정단계에서 꽝이 추가될 경우 해당 항목 노출
  • 꽝 전용 이미지를 별도 업로드할 수 있다. 미업로드 시 기본 이미지 표시(이벤트 빌더 공용)
  • 꽝 결과 이미지는 스크래치 영역 및 보상 획득 팝업에 노출됩니다.

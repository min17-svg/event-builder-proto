배율
프로토타입의 영역(아코디언·팝업·캔버스)을 클릭하면 오른쪽에 해당 기능 설명이 열립니다.
프로토타입은 실제 동작합니다 — 세부 설정 팝업, 라디오 전환, KR/EN 토글, 피그마 가져오기 모두 시연 가능.
기능 설명 — EVENT_MISSION_CARD
미션 카드형 이벤트 화면을 운영자가 직접 설정하는 빌더. 좌측 미리보기 캔버스(1780×890)에 우측 패널의 설정이 즉시 반영되며, 피그마 에셋 일괄 적용과 KR/EN 미리보기를 지원한다.
_01이벤트 화면 미리보기 캔버스›
EVENT_MISSION_CARD_01
이벤트 화면 미리보기 캔버스
조회인터랙티브 미리보기 캔버스
유저 노출 화면을 1780×890 캔버스로 미리보기. 배경 / LNB 배너 6개 / 헤더(기간 정보 + 기능 버튼) / 툴바(초기화 타이머 + 일괄 수령) / 미션 카드 리스트로 구성.
  • 카드 상태 4종: Locked / InProgress / Claimable / Claimed
  • 카드 구성: 미션명·진행도, 인포 아이콘, 리워드 이미지+수량, 리워드명, 보상받기 버튼
  • Claimable 버튼 클릭 → 보상 획득 결과 팝업 미리보기
_02미션/리워드 툴팁›
EVENT_MISSION_CARD_02
미션/리워드 툴팁 (캔버스 내)
조회툴팁 (클릭 토글)
인포 아이콘 클릭 → 미션 툴팁, 리워드 이미지 클릭 → 리워드 툴팁(일반/패키지 2종). 바깥 클릭 시 닫힘.
  • 위치: 아이콘 상단 16px, 상단 협소 시 하단 전환, 좌우 캔버스 내 클램핑
  • 패키지형은 구성 리워드 목록 표시
⚠ 확인 필요툴팁 색상 연동 방식 (프로토타입에 "공통 코드로 수정 예정" 주석)
_03피그마 에셋 가져오기›
EVENT_MISSION_CARD_03
피그마 에셋 가져오기
수정모달 (URL 입력 + 매칭 테이블)
피그마 URL 입력 → fileKey/nodeId 파싱 → asset_ 접두어 프레임 재귀 수집 → 슬롯 매핑 테이블과 이름 기반 자동 매칭 → 일괄 적용.
  • 색상 자동 추출: 완성본 시안에서 텍스트/배경 색상(SOLID·그라데이션) 추출 후 컬러피커 적용
  • 피그마 이미지 URL 직접 사용 (CORS 우회)
연동 고려사항피그마 REST API (노드 트리 조회, 이미지 URL 발급)
⚠ 확인 필요API 토큰 인증 주체(서버/개인) · 피그마 이미지 URL 만료 대응(CDN 재업로드)
_04미리보기 언어 전환 (KR/EN)›
EVENT_MISSION_CARD_04
미리보기 언어 전환 (KR/EN)
조회토글 버튼 그룹
KR/EN 토글로 미리보기 언어 전환. 이미지는 언어별 슬롯 분리 저장, 텍스트는 매핑 테이블 기반 다국어 전환.
  • EN 이미지 등록 여부를 토글 버튼 green dot으로 표시
⚠ 확인 필요EN 이미지 미등록 슬롯의 폴백 정책 (KR 유지 여부)
_05기간 UI 설정›
EVENT_MISSION_CARD_05
기간 UI 설정
수정아코디언 + 라디오 + 컬러피커
이벤트 기간/리워드 수령 기간 표기 각 8종(타이머·미표기·날짜 포맷 6종), 미션 초기화 표기 2종, 배경 색상.
  • 기본값: 이벤트 기간 YYYY.MM.DD 포맷 / 수령 기간 미표기 / 초기화 타이머 노출
  • 두 기간 모두 "표기 없음" → 기간 영역 전체 숨김
  • 배경 색상은 기간 영역·초기화 영역 공통 적용

_07LNB 세부 설정 팝업›
EVENT_MISSION_CARD_07
LNB 세부 설정 팝업
수정팝업 700px (라디오 + 업로드 + 텍스트)
입력 방식 2종: 이미지만 업로드 / 이미지+텍스트 입력(팝업 높이 확장).
  • 이미지만 저장: LNB 활성 아이템 적용 + 기존 텍스트 숨김
  • 이미지+텍스트 저장: 텍스트 미입력 시 원래 텍스트 복구/숨김
  • X/취소/오버레이 → 변경사항 미적용 닫기

EVENT_MISSION_CARD_09
배경 세부 설정 팝업

전체 배경 이미지를 KR/EN 언어별 업로드. 저장 시 KR 이미지가 캔버스 배경에 반영되고 EN 이미지는 언어 전환 시 적용된다.
_10기본 UI 설정 (미션 카드)›
EVENT_MISSION_CARD_10
기본 UI 설정 (미션 카드)
수정아코디언 + 라디오 + 컬러피커
리워드 표기법 3종, 스크롤 방향, 레이아웃, 색상 3종 설정. 변경 즉시 캔버스 반영.
  • 가로 선택: 사이즈 설정(기본/확대형) 노출
  • 세로 선택: 열 개수(3/5열)·영역 정렬(3열 전용)·내부 정렬 노출, 사이즈 기본(M) 강제
  • 스크롤 방향 변경 시 모든 하위 설정 초기화
  • 이미지+텍스트 표기 선택 시 "수량 배경 색상" 행 숨김
  • 색상: 컬러칩 ↔ hex 양방향 연동 (3자리 단축 입력 지원)
⚠ 확인 필요세부 설정 버튼 — 프로토타입 원본에 [확인 필요] 주석 존재 (노출 위치/명칭 확정 필요)
